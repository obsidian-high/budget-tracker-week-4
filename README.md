# SpendWise Dashboard

SpendWise is a modern financial dashboard shell built with HTML and CSS.

The project focuses on creating a clean and responsive dashboard structure using CSS Grid, Flexbox, CSS custom properties, responsive media queries, and accessible card micro-interactions.

The financial information displayed in the dashboard is static and is included to demonstrate the visual structure of the application.
