# SpendWise Dashboard

SpendWise is a responsive financial dashboard shell built with HTML and CSS.

The project focuses on using CSS Grid for the main page structure and Flexbox for internal component alignment. It also demonstrates CSS custom properties, responsive design, accessibility, hover/focus micro-interactions, and a system-preference dark theme.

The financial information shown is static and is only used to demonstrate the dashboard layout.
